EL DESAFÍO COHETE DE PÓLVORA

01 // OBJETIVO

Objetivo del Proyecto

Diseñar, ensamblar y ejecutar el lanzamiento exitoso de una unidad aerodinámica propulsada por combustible sólido de pólvora, demostrando estabilidad, alcance computado y recuperación segura.

02 // SINALOA OPR

Innovación Sinaloense

Desarrollado como prototipo de evaluación técnica en 2026, combinando física aplicada, cálculos de trayectoria y el distintivo sello conceptual de Tecatex Aerospace.

// ARQUITECTURA TÉCNICA

ESPECIFICACIONES DEL VECTOR

01

Propulsión Sólida

Núcleo reactivo de pólvora optimizado para impulso inicial sostenido y máxima aceleración vertical.

02

Fuselaje Aerodinámico

Estructura ligera ultra-resistente diseñada bajo tolerancias mínimas para minimizar el arrastre.

03

Aero-Estabilidad

Aletas estabilizadoras simétricas calibradas para trayectoria parabólica rectilínea.
